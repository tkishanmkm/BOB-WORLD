# **App Name**: BankBuddy

## Core Features:

- Account Details Display: Display account details such as name, account number, IFSC code in a clear and editable format.
- Account Balance Management: Show account balance in INR and allow it to be edited with a single button click.
- E-Passbook Simulation: Simulate an E-passbook displaying transactions in a chronological order. Enable adding or deleting transactions with a single button.
- AI-Powered Statement Analysis: Generate a summary of the account statement, highlighting key transactions and providing insights using a generative AI tool.

## Style Guidelines:

- The same UI and color scheme as the images uploaded by the user to evoke familiarity.
- Clean and intuitive layout with clearly defined sections for account details, balance, and transactions, mimicking the uploaded images.
- Use recognizable icons for different transaction types and actions, consistent with the style of the provided images.
- Subtle transitions and animations to indicate successful edits and updates, following the patterns observed in the example images.
